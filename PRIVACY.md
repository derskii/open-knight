# Конфиденциальность Open Knight 1.0

Расширение не отправляет позиции, партии, историю браузера или содержимое страниц на сервер. Нет аккаунтов, аналитики, рекламных SDK, телеметрии, облачных API и удалённо исполняемого кода. Движки находятся в пакете расширения.

Разрешения:

- `storage`: передача выбранной позиции между окном расширения и доской через локальное хранилище Firefox.
- `activeTab`: работа с выбранной пользователем вкладкой.
- доступ к `chess.com` и `lichess.org`: чтение фигур и записи ходов из DOM и отрисовка стрелок поверх доски. Пароли, cookies, токены и сетевой трафик не читаются. Автоходов нет.

Библиотека, задачи, прогресс и настройки хранятся в localStorage в контексте расширения или сайта. Они доступны только в соответствующем профиле браузера. Пользователь может экспортировать и удалить записи через интерфейс или очистить данные расширения/сайта.

На GitHub Pages браузер загружает интерфейс и выбранный движок с хостинга GitHub; хостинг обрабатывает обычные HTTP-запросы. Обработка шахматных позиций происходит локально. Ссылки GitHub открываются только при переходе пользователя. Веб-версия не является PWA и не гарантирует доступность офлайн.

Пакет Lite не содержит Full и не скачивает исполняемый код. Для Full нужно установить полную сборку.
