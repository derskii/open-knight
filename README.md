# ♞ Open Knight

Открытый шахматный помощник для **Firefox 140+**. Stockfish 19 Lite и Full, локальный анализ без подписки и трекеров.

**[Открыть доску и страницу проекта](https://derskii.github.io/open-knight/)** · [Лицензия](LICENSE) · [Конфиденциальность](PRIVACY.md)

## Что работает

- Stockfish.js **19.0.1**, однопоточные JS/WASM: Lite **1 874 201 байт**, Full **99 197 184 байт** (~94,6 МиБ). Полный ZIP содержит оба движка; Lite ZIP — только Lite. В Lite-сборке Full отключён, удалённый исполняемый код не загружается.
- До 5 отображаемых линий, глубина 12–60, время 0,5–60 секунд, Hash 16–256 МБ. Это максимальная глубина: поиск может закончиться раньше по времени.
- Предварительное качество всех допустимых ходов: выберите фигуру и увидите проценты на полях назначения. Для превращений метка поля показывает лучшее превращение; выбор фигуры превращения остаётся отдельным.
- **Диапазон подсказок**, например **60–70%**, с независимыми минимумом/максимумом и случайным выбором внутри диапазона. Фильтр строгий: нет подходящих ходов — нет стрелок.
- Импорт FEN/PGN, перемещение по записи, ответвления, рокировка, взятие на проходе и выбор превращения, экспорт PGN.
- Последовательный разбор партии, график оценки, эвристические метки ошибок и сохранение ошибки как задачи.
- Редактор FEN, 8 учебных дебютных линий, 4 стартовые задачи + собственные задачи, локальная библиотека, JSON backup/restore.
- Боковая панель Firefox, чтение досок Chess.com / Lichess и стрелки с качеством хода на сайте. Нет автоматического выполнения ходов.

## Как считается качество

`quality = round(100 * exp(-max(0, bestScore - moveScore) / 300))`, где оценки приведены к стороне, которая ходит, и выражены в сотых пешки. Лучший найденный ход получает 100%; потеря 1 пешки — около 72%, 1,5 пешек — около 61%. Это **собственная относительная эвристика**, не точность партии Chess.com и не вероятность победы. Проценты меняются с глубиной. В режиме предоценки Stockfish анализирует все допустимые корневые ходы (MultiPV); под лимитом времени у линий могут быть разные завершённые глубины, отображаемые отдельно. Больше MultiPV означает меньшую глубину за то же время.

## Установка Firefox

1. Скачайте `open-knight-full-1.0.0.zip` или `open-knight-lite-1.0.0.zip` со страницы проекта или Releases и распакуйте.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. Нажмите **«Загрузить временное дополнение»** и выберите распакованный `manifest.json`.
4. Откройте значок Open Knight → **«Открыть боковую панель»**. На Chess.com/Lichess нажмите **«Подключить доску сайта»** и при необходимости **«Следить за позицией сайта»**. После загрузки расширения уже открытые вкладки шахматных сайтов нужно перезагрузить.

Временное дополнение удаляется после перезапуска Firefox. Для постоянной установки требуется подпись Mozilla; эта версия пока не подписана и не размещена на AMO. Чтобы подписать самостоятельно: создайте учётную запись разработчика на addons.mozilla.org, получите AMO API credentials, затем `npx web-ext sign --source-dir dist/firefox --channel unlisted --api-key <issuer> --api-secret <secret>`. Не добавляйте секреты в Git. Проверка Mozilla может быть асинхронной.

## Точность чтения сайтов

Расширение сначала ищет полную FEN, затем восстанавливает её из записи ходов и проверяет совпадение расположения фигур. Если доступно только расположение, очередь хода может потребовать ручного выбора; рокировка и en passant не восстанавливаются. Интерфейс отмечает этот случай. Для точной позиции используйте импорт FEN. DOM сайта может меняться; адаптеры и тесты находятся в `src/capture.js` и `tests/`.

## Сборка

Node.js 22+ (проверено на 24). Все зависимости закреплены в `package-lock.json`.

```sh
npm ci
npm test
npm run build
npm run lint:extension
npm run package
npm run serve
```

`dist/firefox` — временное дополнение; `dist/site` — GitHub Pages; `artifacts` — ZIP-сборки. Сервер: http://127.0.0.1:4173. Сеть требуется для установки npm-зависимостей. Движки включены в расширение; веб-версия загружает только выбранный движок с того же сайта.

## GitHub Pages и Releases

В Settings → Pages выберите Source **GitHub Actions**. Workflow `.github/workflows/release.yml` проверяет код, собирает ZIP и публикует страницу при push в main. Для релиза создайте тег `v1.0.0`: workflow приложит ZIP к GitHub Release. Публикация на AMO не автоматизирована.

Соответствующий исходный код движка закреплён на коммите `0d5dd7944f88c817c07a26bc4fb1905d5f9c46d6` и скачивается закреплённым скриптом в `vendor-source/` и включается в каждую сборку. В нём есть оригинальные build.js, Makefile, инструкции Emscripten, идентификаторы сетей и скрипт их загрузки. Для повторного получения архива: `node scripts/fetch-source.mjs`.

Проект независимый; сторонние бренды, закрытый код и платные сервисы ChessSolve не используются. Идеи общедоступных функций реализованы заново.

## Проверки

`npm test` проверяет 23 случая шахматной логики, диапазонов качества и адаптеров доски. `npm run lint:extension` проверяет манифест и собственный код; отдельно сообщает два известных предупреждения парсера Mozilla в неизменённых Emscripten-загрузчиках Stockfish (`Unexpected Callee` для `(void 0)(...)`). Другие предупреждения приводят к ошибке проверки.
